# 🎓 THESIS_GEN — Генератор тем кваліфікаційних робіт

**THESIS_GEN** — веб-застосунок на базі Django, у якому реалізовано мультиагентну систему штучного інтелекту для генерації, рецензування та оцінювання тем дипломних, курсових та кваліфікаційних робіт у реальному часі.

---

## 📌 Головна концепція (Мультиагентні дебати)

Замість простого одноразового запиту до однієї нейромережі, генерація побудована як дебати трьох незалежних ШІ-агентів:

1. **Генератор (Generator)** — виступає в ролі досвідченого наукового керівника. Формує список із 5 тем відповідно до спеціальності, освітнього рівня, інтересів та ключових слів студента (основний провайдер: **Google Gemini**).
2. **Критик (Critic)** — виступає в ролі суворого рецензента. Аналізує запропоновані теми, знаходить слабкі місця, перевіряє актуальність, практичну цінність та складність (основний провайдер: **Groq / LLaMA**).
3. **Суддя (Judge)** — незалежний арбітр. Зіставляє пропозиції Генератора із зауваженнями Критика, виставляє оцінки від 1.0 до 10.0 та дає фінальний вердикт (основний провайдер: **OpenRouter / DeepSeek / Meta-LLaMA**).

> **Відмовостійкість (Fallback-ланцюжок):** якщо у основного API вичерпано ліміти або сталася помилка 429/500, система автоматично перемикається на резервних провайдерів без переривання сесії.

## 🛠 Технологічний стек

* **Бекенд:** Python 3.14, Django 6.1
* **База даних:** MySQL 8.4 (драйвер `mysqlclient`), кодування `utf8mb4`
* **Фронтенд:** HTML5, Bootstrap 5.3, кастомний Neo-Brutalist CSS (`brytal_style.css`), Vanilla JavaScript
* **ШІ-провайдери:** Gemini API, Groq Cloud API, OpenRouter API (пряма взаємодія через `requests` та JSON-режим)
* **Асинхронна доставка:** Server-Sent Events (SSE / `StreamingHttpResponse`) для трансляції думок агентів у реальному часі
* **Безпека паролів:** PBKDF2-HMAC-SHA256 (1 500 000 раундів хешування)

## 🗄 Моделі бази даних (`topics/models.py`)

1. **`Interest`** — довідник інтересів (30+ попередньо завантажених напрямів: ШІ, Веб, Кібербезпека, DevOps, Бізнес-аналітика тощо).
2. **`StudentInterest`** — зв'язок інтересу з конкретним користувачем, збереження ваги та вибору за замовчуванням.
3. **`Question` / `Option` / `OptionInterest`** — інтерактивний профорієнтаційний тест із ваговими коефіцієнтами для визначення інтересів.
4. **`GenerationSession`** — сесія генерації:
   * Студент (або `guest_key` для гостей без акаунту)
   * Спеціальність, індустрія, заклад (`school`, `college`, `university`)
   * Рівень освіти (`bachelor`, `master`)
   * Тип роботи (`practical`, `theoretical`, `mixed`)
   * Кількість кіл дебатів (від 1 до 3)
   * `keywords` — ключові слова користувача
   * Зв'язок Many-to-Many з `Interest`
   * Статус (`running`, `done`, `error`)
5. **`GeneratedTopic`** — згенерована тема:
   * Назва, обґрунтування (`why`), складність (`easy`, `medium`, `hard`)
   * Оцінка (від 1.0 до 10.0), коментар Критика
   * Номер кола (`round`), прапорець `is_pinned` (обрана тема)
6. **`AgentMessage`** — повний покроковий аудит-лог дебатів (хто, коли і що згенерував).
7. **`HomePageImage`** — банер головної сторінки з адмінки.

## 🚀 Ключовий функціонал системи

* **Пробна генерація (Guest Mode):** гість може провести 1 генерацію без реєстрації (прив'язка до ключа сесії Django).
* **Багатоколові дебати (Multi-round):**
  * Можливість провести до 3 кіл.
  * Кнопка **[ ОБРАТИ ]** фіксує тему з поточного кола — на наступному колі Генератор бере її за основу і вдосконалює.
  * Кнопка **ДОДАТИ (В ОБРАНЕ)** закріплює найкращі теми сесії.
* **Тест інтересів:** опитування для тих, хто не визначився з темою; результати автоматично підставляються в параметри сесії.
* **Історія та керування:**
  * Фільтрація за статусом, типом закладу та сортування за часом.
  * Повнотекстовий пошук за назвою, інтересами та ключовими словами.
  * Масове видалення сесій.
  * Експорт тем на Email.
* **AI Sandbox (Пісочниця промптів для staff):**
  * Автоматичний цикл оптимізації промптів: інший LLM-агент аналізує згенеровані результати і сам переписує системний промпт для підвищення якості відповідей.
* **Neo-Brutalism UI:**
  * Контрастний ретро-футуристичний дизайн, адаптивні вікна терміналів, перемикач темної/світлої теми.
