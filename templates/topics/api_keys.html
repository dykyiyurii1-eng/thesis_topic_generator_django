[ ВСЕ ПРО ВЛАСНІ API-КЛЮЧІ ]

API-ключ — це персональний цифровий пропуск до нейромережі. Ви безкоштовно створюєте його на офіційному сайті провайдера, копіюєте та вставляєте сюди.

[1] GOOGLE GEMINI
РЕКОМЕНДОВАНО
  1. Перейдіть на aistudio.google.com/app/apikey
  2. Увійдіть під своїм звичайним Google-акаунтом
  3. Натисніть «Create API key»
  4. Скопіюйте згенерований рядок (починається з AIzaSy...)
  5. Вставте у форму нижче та виберіть Gemini
> БЕЗКОШТОВНИЙ ЛІМІТ: ~1500 запитів/день.
[2] GROQ
НАЙШВИДШИЙ
  1. Відкрийте console.groq.com/keys
  2. Авторизуйтесь (Google, GitHub або Email)
  3. Натисніть «Create API Key»
  4. Скопіюйте ключ (починається з gsk_...)
  5. Вставте у форму нижче та виберіть Groq
> БЕЗКОШТОВНИЙ ЛІМІТ: 14 400 запитів/день.
[3] OPENROUTER
100+ МОДЕЛЕЙ
  1. Відкрийте openrouter.ai/keys
  2. Увійдіть та створіть ключ через «Create Key»
  3. Скопіюйте ключ (починається з sk-or-v1-...)
  4. Вставте у форму та виберіть OpenRouter
> ПІДТРИМКА БЕЗКОШТОВНИХ МОДЕЛЕЙ (Llama, Mistral тощо).
⚠️ УВАГА: Ніколи не передавайте свій ключ стороннім особам. Ви можете анулювати його на сайті провайдера у будь-яку секунду.

Ми ставимося до ваших ключів як до паролів. Пояснюємо технічну реалізацію без маркетингових вигадок:

01
ШИФРУВАННЯ НА БОЦІ СЕРВЕРА

Ключ ніколи не зберігається відкритим текстом. Він миттєво шифрується алгоритмом Fernet (AES-128-CBC). Навіть при прямому читанні бази даних видно лише зашифрований хеш.

02
НУЛЬОВИЙ ВИВІД У БРАУЗЕР

Повний ключ ніколи не рендериться в HTML, JSON-відповіді або логи сервера. У інтерфейсі показуються лише останні 4 символи (наприклад, •••• 9xKm).

03
ІЗОЛЯЦІЯ ДЛЯ ВАШИХ СЕСІЙ

Ключ підтягується виключно при генераціях тем вашого акаунту. Жоден інший користувач чи адміністратор не може скористатися вашим лімітом.

04
ПОВНИЙ КОНТРОЛЬ ТА ВИДАЛЕННЯ

В один клік ключ безповоротно видаляється з бази даних, після чого система переходить на загальні резервні ключі сервера.

🤝 ЧЕСНО: Ми не стверджуємо «100% захист», бо в комп'ютерній безпеці такого не існує. Якщо ви не бажаєте додавати ключ — не додавайте, система продовжить працювати на загальному ліміті.
SYS.SECURITY // FERNET_ENCRYPTED
> БЕЗПЕКА ВАШОГО API-КЛЮЧА
  • Шифрується алгоритмом Fernet (AES-128-CBC) до збереження в базу.
  • Повний ключ ніколи не потрапляє в браузер, логи чи стороннім.
  • Використовується суто для ваших генерацій та розширює денний ліміт (до 50).
  • Ви можете видалити ключ у будь-який момент в один клік.
